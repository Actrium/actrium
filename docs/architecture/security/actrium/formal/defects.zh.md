## 2. 仍然开放的模型／设计缺陷

### D-ORACLE-01　`covers_recover_paths` 与 A2 是预言机

**现象：** Retain 判 \(0\) 依赖「证据覆盖全部恢复路径」；能力闭合依赖 Host 看见全部旁路。形式系统把它们写成公理。

**影响：** Native、GPU、管理面、调试器上的绿色在现实中通常推不出来。

**处理：** 证不了就保持黄／红。不能把「已启用 CC」写成覆盖全部路径。

本节不再把切面、世代、编码、局部继续、本地时钟、验证者挑选、状态回滚和目标分类列为开放设计缺陷；它们已写入规范并有机器核验。信错唯一验证者仍是 A6／策略前提，见 §3。目标分类规则（D-CLASS-01）的现实执行力依赖 Host 能识别 Actr 端点，属 A2 类义务。

## 3. 固有界限（不是缺陷，但不能称为已证）

这些不是规范写错，而是任何相对安全理论都无法在本文内消去的前提：

1. **A2 完整中介** — 需要 Host／沙箱／内核证据。
2. **A4／A5 计算密码学** — 需要具体套件上的 Tamarin／ProVerif 或标准归约；当前只有 Dolev-Yao 有界穷举。
3. **A6 证据可靠性** — 需要厂商证明格式与测量覆盖。
4. **A8 可信时间与密钥不可恢复** — 需要平台 Profile。
5. **A9 完整发现** — 需要可认证的反向依赖索引。
6. **侧信道、元数据、物理攻击、Principal 治理** — 明确非目标。
